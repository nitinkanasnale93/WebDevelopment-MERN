Alert & Prompt

JavaScript Browser Dialogs

1. Alert

Alert displays an alert message on the page.

alert("Something is wrong!");
Example: An alert can be used to show warnings, notifications, or important messages.

2. Prompt

Prompt displays a dialog box that asks the user for some input.

prompt("Please enter your roll no.");
Example: A prompt can be used to take information such as name, age, roll number, etc.

Alert vs Prompt

Method Purpose User Input
alert() Displays a message No
prompt() Asks the user for input Yes

Quick Notes

  • alert() → Shows a message.
  • prompt() → Takes input from the user.
  • Both are browser dialog boxes.
  • prompt() returns the value entered by the user.
