Switch Statement

JavaScript Conditional Statement

What is a Switch Statement?

A switch statement is used when we have multiple fixed values that we need to compare with one value.

It is an alternative to using many else if statements.

Basic Structure

switch (value) {

    case "value1":
        // code
        break;

    case "value2":
        // code
        break;

    case "value3":
        // code
        break;

    default:
        // code
}

Important Keywords

Keyword Purpose
switch Starts the switch statement.
case Defines a value to compare.
break Stops execution after a matching case.
default Runs when no case matches.

Example: Traffic Light

Color Action
Red Stop
Yellow Slow down
Green Go
Other Broken Light

How It Works

  1. The switch receives a value.
  2. JavaScript checks each case.
  3. When a matching case is found, its code runs.
  4. break stops the switch.
  5. If nothing matches, default runs.

Quick Notes

  • Use switch for multiple fixed values.
  • Use case to define possible values.
  • Use break to stop after a match.
  • Use default when no case matches.
  • Switch statements are useful for menus, traffic lights, days, months, and other fixed choices.
