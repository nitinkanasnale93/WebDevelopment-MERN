trim() Method

JavaScript String Method

What is trim()?

The trim() method removes whitespace from the beginning and end of a string.

Syntax: string.trim()

Example

Consider a string containing spaces:

"    apna    "

After applying trim():

'apna'

What Does trim() Remove?

Beginning

Removes unnecessary whitespace from the beginning of a string.

End

Removes unnecessary whitespace from the end of a string.

Note: trim() does not remove spaces between words.

Strings are Immutable

Strings in JavaScript are immutable.

This means that the original string cannot be changed directly.

Important: trim() does not change the original string.

trim() Returns a New String

The trim() method returns a new string after removing whitespace.

Original String

"   apna   "

The original string remains unchanged.

New String

'apna'

trim() returns the cleaned string.

Related Methods

Method Use
trim() Removes whitespace from both beginning and end.
trimStart() Removes whitespace from the beginning.
trimEnd() Removes whitespace from the end.

Key Points

  • trim() removes whitespace from both sides.
  • It does not remove spaces between words.
  • Strings are immutable.
  • trim() does not modify the original string.
  • trim() returns a new string.

Remember

trim() = Remove whitespace from both ends
