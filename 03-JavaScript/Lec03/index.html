JavaScript String & Array Methods

Simple notes + examples for revision

1. trim()

What it does: Removes extra spaces from the beginning and end of a string.

let msg = "   Hello   ";
console.log(msg.trim());

Output: Hello

2. trim() Does Not Change the Original String

What it does: trim() gives back a cleaned string. It does not change the original string.

let msg = "apna   ";
let str = msg.trim();

console.log(msg);
console.log(str);

Remember: Original = "apna ", New value = "apna"

3. toUpperCase() & toLowerCase()

What they do: Change all letters to uppercase or lowercase.

let name = "Vishwa";

console.log(name.toUpperCase());
console.log(name.toLowerCase());

Output: VISHWA and vishwa

4. indexOf()

What it does: Tells you where a value starts. If it is not found, it gives -1.

let str = "ILoveCoding";

console.log(str.indexOf("Love"));
console.log(str.indexOf("J"));

Output: 1 and -1

5. slice()

What it does: Takes out a part of a string or array. The ending index is not included.

let msg = "Hello";

console.log(msg.slice(0, 4));

Output: Hell

6. Negative Index in slice()

What it does: A negative index starts counting from the end.

let msg = "NationalServiceScheme";

console.log(msg.slice(-1));
console.log(msg.slice(-2));

Output: e and me

7. replace()

What it does: Replaces a matching part of a string with something else.

let msg = "Love";

console.log(msg.replace("Love", "do"));
console.log(msg.replace("o", "x"));

Output: do and Lxve

8. repeat()

What it does: Repeats a string as many times as you tell it.

let msg = "Love";

console.log(msg.repeat(3));

Output: LoveLoveLove

9. Method Chaining

What it does: Lets you use one method after another on the same value.

let msg = " Help! ";

console.log(msg.trim().toUpperCase());

Output: HELP!

Array Methods

Working with multiple values

10. Creating and Accessing an Array

What it does: An array stores multiple values. We use an index to get a value.

let students = ["Kannika", "Nitin", "Raju"];

console.log(students[0]);
console.log(students.length);
console.log(students[0][0]);

Output: Kannika, 3, K

11. Updating Array Elements

What it does: Use the index to change an existing value.

let fruits = ["Mango", "Apple", "Litchi"];

fruits[0] = "Banana";

console.log(fruits);

Result: ["Banana", "Apple", "Litchi"]

12. push() and pop()

push(): Adds an element at the end.

pop(): Removes the last element.

let cars = ["BMW", "THAR", "DEFENDER"];

cars.push("Ferrari");
console.log(cars);

cars.pop();
console.log(cars);

13. unshift() and shift()

unshift(): Adds an element at the beginning.

shift(): Removes the first element.

let cars = ["BMW", "THAR", "DEFENDER"];

cars.unshift("Ferrari");
console.log(cars);

cars.shift();
console.log(cars);

14. indexOf() and includes()

indexOf(): Gives the index. If not found, it gives -1.

includes(): Checks whether the value exists and gives true or false.

let cars = ["BMW", "THAR", "DEFENDER"];

console.log(cars.indexOf("BMW"));
console.log(cars.includes("BMW"));
console.log(cars.includes("XUV"));

15. slice() in Arrays

What it does: Takes out a part of an array without changing the original array.

let cars = ["BMW", "THAR", "DEFENDER", "RANGEROVER"];

console.log(cars.slice(1));
console.log(cars.slice(1, 3));
console.log(cars.slice(-2));

16. concat()

What it does: Joins two arrays and gives a new array.

let primary = ["Red", "Blue", "Green"];
let secondary = ["Yellow", "Orange", "Purple"];

let colors = primary.concat(secondary);

console.log(colors);

Important: The original arrays are not changed.

17. splice() - Remove Elements

What it does: Removes elements from the original array.

let colors = ["Red", "Blue", "Green", "Yellow", "Orange"];

console.log(colors.splice(3));
console.log(colors);

Here: splice(3) removes everything from index 3 onward.

18. splice() - Remove One Element

What it does: Removes a specific number of elements from a specific index.

let colors = ["Red", "Blue", "Green", "Yellow"];

console.log(colors.splice(1, 1));
console.log(colors);

Meaning: Start at index 1 and remove 1 element.

19. splice() - Remove and Add

What it does: Removes an element and adds new elements in its place.

let colors = ["Red", "Blue", "Green", "Yellow"];

console.log(colors.splice(2, 1, "Pink", "Lightgreen"));
console.log(colors);

Easy trick: splice(index, deleteCount, newValue) = remove + add/change.

20. splice() - Add Without Removing

What it does: Adds new elements at a particular position without deleting anything.

let colors = ["Red", "Blue", "Green"];

colors.splice(1, 0, "White", "Black");

console.log(colors);

Important: 0 means remove nothing.

21. reverse()

What it does: Reverses the order of the array.

let colors = ["Red", "Blue", "Green"];

console.log(colors.reverse());

Important: reverse() changes the original array.

22. sort()

What it does: Sorts an array. For numbers, normal sort() treats them like strings.

let num = [93, 53, 26, 31, 100];

console.log(num.sort());

Remember: [100, 26, 31, 53, 93] can happen because the values are compared like strings.

23. Array References

What it means: Two separate arrays with the same values are still different arrays.

let arr1 = [1];
let arr2 = [1];

console.log(arr1 === arr2);

Output: false

24. Same Array Reference

What it means: If you do let arrCopy = arr, both variables point to the same array.

let arr = ["a", "b"];
let arrCopy = arr;

arrCopy.push("c");

console.log(arrCopy);
console.log(arr);

Both show ["a", "b", "c"] because they refer to the same array.

25. Constant Array

What it means: With const, you cannot assign a completely new array, but you can change the contents.

const array = [1, 2, 3];

array.push(4);
console.log(array);

array.pop();
console.log(array);

// array = [5, 6, 7]; // ❌ Not allowed

Easy trick: const locks the reference, not the array contents.

26. Nested Arrays

What it means: An array can contain other arrays.

let nums = [[2, 4], [6, 8], [1, 3]];

console.log(nums);
console.log(nums.length);
console.log(nums[0]);
console.log(nums[0][0]);

Think like: nums[row][column]

27. Nested Array - Tic-Tac-Toe

What it does: A nested array can be used to represent rows and columns of a game board.

let game = [
    ["X", null, "O"],
    [" ", null, " "],
    ["O", null, "X"]
];

console.log(game);

Here, each inner array represents one row of the board.

Quick Revision

slice() → take a part   | splice() → remove/add/change   | push() → add at end   | pop() → remove from end   | shift() → remove from start   | unshift() → add at start
