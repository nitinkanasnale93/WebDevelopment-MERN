Comparison

CSS vs Bootstrap

Both can create a toggle menu, but the implementation is different.

Using CSS

In the CSS method, we use a hidden checkbox to control the sidebar.

#check:checked ~ .sidebar_menu {
  left: 0;
}

We manually write the CSS that changes the sidebar from -320px to 0px.

Using Bootstrap

Bootstrap provides built-in components that handle the toggle behavior for us.

data-bs-toggle="collapse"
data-bs-target="#navbar"

Bootstrap's JavaScript handles the opening and closing state, so we don't need to write the :checked CSS logic.

How Bootstrap Does It

In the Bootstrap navbar, the button uses navbar-toggler and Bootstrap's data-bs-toggle attribute.

<button class="navbar-toggler" data-bs-toggle="collapse" data-bs-target="#bootstrapNavbar" >

The menu that should open has the collapse class and the matching ID.

<div class="collapse navbar-collapse" id="bootstrapNavbar" >
